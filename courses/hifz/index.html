The syllabus

What the course covers, in order

  1. Sabaq — the new lesson

    A fixed daily portion, set to what the student can actually hold, recited back to the tutor until it is clean.

  2. Sabqi — recent revision

    The portions of the last several days, recited daily so that new material settles instead of slipping.

  3. Manzil — old revision

    Everything memorised before, cycled on a schedule. This is the part students abandon and the reason most incomplete Hifz is lost.

  4. Tajweed during memorisation

    Corrected while the portion is being learnt, because a mistake memorised is far harder to remove than a mistake read.

  5. Recitation practice

    Reciting aloud, from memory, under listening — which is a different skill from remembering.

Questions

Common questions about this course

How long does it take to memorise the Quran?

There is no honest single answer. It depends on age, hours per day, how much is revised, and how fluent the student's reading already is. A student doing a substantial daily portion with full revision progresses very differently from one studying twice a week. The trial class is where a realistic pace is set.

Can Hifz really be done online?

Yes, because Hifz has always been taught one to one, by listening. The tutor hears every word of sabaq, sabqi and manzil exactly as they would in person.

Do I need to be fluent at reading first?

Yes. Memorising before reading is fluent builds errors into the memory.
